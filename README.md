# Signal392 Technologies LLC website

Static company website for public-sector buyers and prime contractors. The site uses HTML and CSS with no build step or external runtime dependencies.

Open `index.html` directly or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

For GitHub Pages, select **Deploy from a branch** under **Settings → Pages**, then select `main` and `/ (root)`. The relative asset URLs support GitHub Pages project URLs and custom domains.

Email links open the visitor’s email app. The site does not collect form submissions or use analytics.
